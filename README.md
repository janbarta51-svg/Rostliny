# Atlas rostlin

Terénní atlas pro GitHub Pages a Pages CMS.

- 601 unikátních rostlin
- kompletní barvy a období kvetení
- vyhledávání a filtry
- celé fotografie bez ořezu v otevřené kartě
- PWA + offline cache
- editace přes Pages CMS

Web: https://janbarta51-svg.github.io/Rostliny/

Editovatelná data jsou v `content/plants/*.json`; workflow **Publish atlas** po změně spustí `build.py` a publikuje `dist/`.
